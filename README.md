# WordMemo

纯静态、零后端的英语单词学习 PWA，深度适配 PC 与移动端。支持发音朗读、中文默写、错题复习、打卡激励与词库管理。

## 核心功能

- **单词学习**：卡片式浏览，支持自动发音、语速调节、中文释义切换
- **中文默写**：看英文写中文，自动判分，支持多义词匹配与模糊匹配
- **错题复习**：自动收集错题，错误 ≥3 次归为难词，支持针对性重做
- **词库管理**：分组组织、JSON/CSV/DOCX/PDF 导入导出、搜索筛选
- **打卡激励**：连续打卡天数追踪，自动发放成就徽章
- **离线可用**：PWA 支持，可添加到主屏幕，断网也能学
- **双端适配**：移动端手势滑动 + 触控，PC 端键盘快捷键 + 宽屏布局

## 环境要求

- Node.js ≥ 18
- 浏览器：Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+

## 安装与运行

```bash
npm install
npm run dev      # 开发模式，支持热更新
npm run build    # 构建生产版本，输出到 dist/
```

构建产物为纯静态文件，可部署到 GitHub Pages、Vercel、Netlify 等任意静态托管。

## 基本使用

| 操作 | 移动端 | PC 端 |
|------|--------|-------|
| 切换单词 | 左右滑动 | ← → 方向键 |
| 发音 | 点击卡片 | 空格键 |
| 标记已掌握 | 上滑 | 点击按钮 |
| 提交默写 | 点击确定 | Enter / Ctrl+Enter |
| 语速调节 | 底部工具栏 | 快捷键 1/2/3 |
| 快捷键帮助 | — | 按 `?` 键 |

默认内置四级词库，首次使用点击"开始学习"激活音频。学习/默写 ≥5 个单词自动打卡。

## 常见问题

**Q: 发音没声音？**  
首次使用需点击"开始学习"按钮激活音频上下文（浏览器安全策略）。检查是否误触静音。

**Q: 数据会丢失吗？**  
数据存储在浏览器 localStorage 中。清除浏览器数据会导致丢失，建议定期通过词库页导出 JSON 备份。

**Q: 如何导入单词？**  
词库页 → 导入按钮 → 选择 JSON/CSV 文件或粘贴 JSON 文本。导入时自动跳过重复单词。

**Q: 可以跨设备同步吗？**  
零后端架构下不支持自动同步。可通过导出 JSON 文件手动迁移数据。

**Q: 隐私模式下能用吗？**  
部分浏览器隐私模式限制 localStorage，应用会检测并提示切换正常模式。
